Project setup (from scratch)

# 1. Python version
python --version

# 2. Virtual environment
python -m venv .venv

# 3. Activate it
.\.venv\Scripts\Activate.ps1

# 4. Install dependencies
pip install -r requirements.txt

# 5. Start the web app  ->  http://127.0.0.1:5000
python app.py

# 6. Run the tests
python -m pytest -q

Connect Antigravity (MCP host)

Create .agents\mcp_config.json in this project folder (workspace scope), or edit the global %USERPROFILE%\.gemini\config\mcp_config.json. Use the full README section “Antigravity MCP Connection” — it generates the exact absolute paths for this machine. 

{
  "mcpServers": {
    "nexusai": {
      "command": "<ABSOLUTE>\\.venv\\Scripts\\python.exe",
      "args": ["<ABSOLUTE>\\mcp_server.py"],
      "cwd": "<ABSOLUTE>"
    }
  }
}

Restart/refresh the MCP connection afterwards; no API keys are required.
