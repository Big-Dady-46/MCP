How MCP works — 60 seconds

  1. Host — the AI application you talk to (Antigravity, MCP Inspector). It owns the chat and decides when to call a tool.
  2. Client — a small library inside the host that speaks the MCP protocol to one server.
  3. Server — this Python process (mcp_server.py). It advertises tools and executes them.
  4. Tool discovery — on connect the client sends tools/list; the SDK answers with each tool's name, description and JSON Schema (generated from the type hints).
  5. Tool execution — the model picks a tool and arguments → client sends tools/call → the SDK validates arguments against the schema → your Python function runs → result returns as text the model can read.
  6. Shared data — the tool writes to nexusai.db through database.py, the exact same file the web app uses. Create a task here, then refresh My Tasks: it's there.
