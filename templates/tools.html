Test with MCP Inspector

  1. Open a terminal in the project folder and activate the environment: .venv\Scripts\Activate.ps1
  2. Start the Inspector: {{ inspector_cmd }}
  3. Open the URL it prints (usually http://127.0.0.1:5173).
  4. Open the Tools tab — you should see all {{ tools|length }} tools with auto-generated forms.
  5. Call add_task with {"title": "Created from Inspector"}, then list_tasks.
  6. Call complete_task with the returned id, then delete_task with that id.
  7. Switch back to My Tasks in this web app — the same rows changed, because both use nexusai.db.
Inspector needs Node.js (node -v to check). If it's missing, install the free LTS build from nodejs.org — the mcp dev command uses npx under the hood.
